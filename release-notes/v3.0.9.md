MT5700M Manager v3.0.9：界面、共享缓存与短信交互优化。

应用版本 `3.0.9-r1`；原生传输程序保持 `1.0.1-r1`。

### 本版变化

- 保留单一后台采集器和正常 5 秒信号采样，概览与无线页共用缓存。模组忙时优先让位于短信和设置，不增加周期 AT 查询。
- 概览分别刷新信号、接口状态、流量与载波快照；显示真实数据年龄。隐藏页面暂停轮询，离开页面清理计时器；读取失败保留旧值并标记待确认。
- 移动数据、无线、SIM 与高级页先显示框架，较慢的协议、会话、偏好及诊断按需读取。区分主机接口地址与模组会话地址。
- 短信读取失败不再冒充空收件箱；未知设置禁止保存。刷新、发送或删除后局部更新，保留会话、草稿和滚动位置。
- 设置只提交变更项并串行执行，失败停止后续项。保留发送确认、防重复与结果未知保护；模组提交确认不等于收件人已收到。
- 统一字体、间距及深浅色样式，优化手机布局与操作按钮，合并重复倒计时和载波标签；去除正常健康提示的重复英文（#11）。

### 下载与升级

- OpenWrt 24.10.8 SDK：IPK 安装包归档。
- OpenWrt 25.12.6 SDK：APK 安装包归档，附本次构建签名公钥。
- 两套产物均包含应用、简体中文包、原生传输包、构建信息及 SHA256。目标为 `mediatek/filogic`，原生传输包架构为 `aarch64_cortex-a53`。
- 核对 SHA256、目标 ABI、包管理器和依赖后安装；不要混装 IPK/APK，也不要跳过依赖或签名校验。USB 内核驱动必须来自当前固件匹配的软件源。
- 升级前备份配置，预留维护窗口；安装脚本可能重新加载管理服务。升级后强制刷新浏览器。已有配置由包管理器保留，本版不附带任何个人配置或短信数据。

### 验证范围

对应源码已通过完整 Linux 回归、19 项原生传输模拟测试，以及 H5000M 六个 LuCI 页面、手机布局、短信只读查询和 HTTPS 连通性验证。部署优化文件时配置与服务进程保持不变。

本次未发送或删除真实短信、重拨、重启或刷机；源码部署验证不等于新生成安装包的实机安装验收，也不代表所有运营商或主题均完成长期测试。5 秒为正常采样目标，锁占用与退避可能延长成功采样间隔。
